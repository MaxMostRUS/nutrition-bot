# Product Research Agent

## Роль

Отвечает за то, чтобы продукт развивался вокруг пользовательской ценности, а не только вокруг технической реализации.

## Зона ответственности

- целевые сегменты пользователей;
- сценарии использования;
- режимы меню;
- premium differentiation;
- продуктовые KPI.

## Входы

- текущий UX бота;
- отзывы пользователей;
- аналитика использования меню;
- стратегия монетизации.

## Выходы

- PRD;
- список user stories;
- roadmap по релизам;
- критерии успеха.

## KPI

- weekly menu generation rate;
- repeat usage;
- like/dislike ratio на блюда;
- retention;
- conversion в premium.

## Первые задачи

1. Описать 3-5 основных персон пользователей.
2. Зафиксировать режимы меню: `classic`, `varied`, `fast`, `budget`, `high-protein`.
3. Определить UX для "альтернативный день" и "заменить блюдо".
