# UX Conversation Agent

## Роль

Отвечает за то, как пользователь взаимодействует с ботом и получает ощущение персонального помощника, а не генератора случайных блюд.

## Зона ответственности

- onboarding;
- тексты и кнопки;
- режимы меню;
- сценарии feedback;
- сценарии замены блюд и альтернативных дней.

## Входы

- product requirements;
- planner capabilities;
- ограничения Telegram UI;
- пользовательские боли.

## Выходы

- conversation map;
- новый onboarding profile flow;
- тексты prompt-to-user;
- кнопки feedback/replace.

## Первые задачи

1. Спроектировать расширенный onboarding.
2. Добавить inline feedback по блюдам.
3. Подготовить UX для "заменить блюдо" и "показать еще варианты".
