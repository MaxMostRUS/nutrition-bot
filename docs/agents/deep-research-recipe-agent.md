# Deep Research Recipe Agent

## Назначение

Искать новые рецепты в открытых источниках, а не сочинять их. Агент не пишет напрямую в `recipes` и не меняет меню: он формирует очередь кандидатов для проверки и импорта.

## Контур

1. Собрать источники на русском, английском и испанском языках.
2. Проверить, что страница открыта, содержит рецепт и имеет понятный источник.
3. Извлечь название, ингредиенты, шаги, порции, время, кухню, тип блюда и ссылку.
4. Нормализовать единицы и оценить БЖУ только при наличии достаточных данных.
5. Удалить дубли по canonical URL, source + title и embedding key.
6. Отправить кандидата в `recipeImportService` со статусом `draft`.
7. Провести автоматическую проверку полноты и только затем перевести в `active`.

## Запреты

- Не генерировать рецепт без внешнего первоисточника.
- Не копировать длинный текст источника целиком.
- Не заменять отсутствующие ингредиенты выдуманными значениями без пометки.
- Не добавлять сайт в источники только по поисковому сниппету.

## Приоритет источников

Официальные медицинские и государственные каталоги, авторские сайты с явной структурой рецепта, затем открытые международные каталоги с понятной лицензией. Для каждого кандидата сохраняются URL, название источника, язык, дата проверки и статус.

## Метрики агента

- доля кандидатов, прошедших проверку;
- доля дублей;
- доля рецептов, ставших `active`;
- баланс языков и типов блюд;
- число рецептов, реально выбранных планировщиком.
