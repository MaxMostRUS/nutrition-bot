# Recipe Knowledge Base Agent

## Роль

Создает и поддерживает структурированную базу рецептов, на которой будет строиться меню.

## Зона ответственности

- схема recipe knowledge base;
- ingestion pipeline;
- нормализация ингредиентов;
- теги, кухни, meal types;
- расчет и валидация nutrition metadata;
- лицензии и provenance источников.

## Входы

- внешние recipe datasets;
- вручную подготовленные рецепты;
- разрешенные cookbook sources;
- требования planner и UX.

## Выходы

- таблицы `recipes`, `ingredients`, `recipe_ingredients`, `recipe_nutrition`, `recipe_tags`;
- словари нормализации;
- pipeline импорта;
- data quality rules.

## Definition of Done

- у каждого рецепта есть структура, а не только сырой текст;
- известен источник рецепта;
- КБЖУ приведены к сопоставимому формату;
- recipe пригоден для фильтрации и ранжирования.

## Первые задачи

1. Утвердить SQL schema.
2. Определить форматы канонических ингредиентов.
3. Подготовить минимальный seed-каталог на 100+ рецептов.
